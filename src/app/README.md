Christoffels Kichen Menu App

A mobile app managing the menu at Christoffels Kitchen

What does the app do?
The app lets the chef add, view, search, edit and also delete menu itmes. It also shows menu statistics like the total items added and the average price.

The main features
- Add Menu Item: add dish name, description, course( starter, main or dessert) and the price
- Edit Menu Item: to change the dish name, then click update menu item
- Delete Menu Item: to remove a dish from the menu
- Search: search for a dish by its name
- Filter: filter by course,all/ starter/ main course/ dessert
- Menu statistics: shows the total items, average price, total price, starters, main course, dessert
- Validation: if you click save menu item with empty fields, a error message appears
- Total price: automatically calculates the total price of all filtered items

Technologies used:
- Reactive Native
- Expo
- TypeScript
- React Native Picker: for the course dropdown

How to run the app
1. Install Node.js and Expo
2. Open the project folder in Visual Studio Code
3. Install dependencies

Start the app:
npx expo start, press w to open web browser 

How to use the app:
1. Fil in the dish name, description, course and price
2. Click save menu item to add it
3. To edit, click edit on the dish, then click update menu item
4. To delete, click delete
5. Use the search to find the dish quicker
6. Use filter by course to see the starters, main course or desserts
7. Scroll down to see the menu statistics under the total menu items
